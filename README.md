# 奇思妙取 · 本地取名工作台

> 该工作台由 Oddest 娱乐制作，生成内容仅供参考。
> 一款**只在本机浏览器运行、数据留在本机**的离线取名工具，无需联网、登录、云数据库与部署。

---

## 1. 项目解决什么问题

日常起名（给宝宝、给宠物、或为名字做校验）往往要打开多个网站、来回切换工具，还要担心资料上网、数据被平台留存。

这个项目把 **新生儿取名、生辰八字取名、诗词取名、宠物取名、名字解析及评分** 五件事整合进一个本地单页应用，做成一台"取名工作台"：

- **全部离线运行**：双击打开即可用，不联网、不接大模型接口，生成逻辑完全在本地完成。
- **数据保存在本机**：所有记录、收藏、素材、偏好写入浏览器本地存储（IndexedDB），刷新、关闭、重启都不丢失。
- **私密**：不登录、不上传，起名过程与结果只属于你自己。
- **可备份**：一键导出 JSON 备份，换电脑/清浏览器前可随时导出留存。

## 2. 主要功能

| 模块 | 说明 |
|---|---|
| **首页工作台** | 快速 AI 取名（内置数据库直出）、上传自定义文献取名、5 个模块摘要卡片、最近记录列表 |
| **新生儿取名** | 按姓氏、性别、字辈、避讳字、期望风格生成名字；卡片展示拼音/笔画/五行/寓意；支持换一批与精选名字参考 |
| **生辰八字取名** | 输入出生信息 → 本地排盘（四柱干支、五行统计、喜用/缺失提示）→ 按五行补益推荐名字，每个字标注五行 |
| **诗词取名** | 内置诗词库按出处分类浏览、关键词检索（名句 + 全篇正文均可命中）、点选名句提炼好字取名，名字带出处原文与释义 |
| **宠物取名** | 按宠物类型、性别、毛色、性格与风格生成名字，支持中英文名切换、换一批 |
| **名字解析及评分** | 输入任意名字，逐字解析拼音/声调/笔画/五行/寓意，按 6 个维度评分并给出综合分与点评 |
| **收藏夹** | 跨模块统一查看所有收藏的名字 |
| **历史记录** | 所有取名、解析、文献操作自动留痕，可按时间回看 |
| **设置** | 保存默认姓氏、性别、风格、宠物类型，用于各模块自动带入 |
| **数据备份 / 恢复** | 顶栏一键导出 JSON、一键导入恢复 |

### 内置数据（随应用打包，只读）
- 常用汉字库：337 字（含拼音、声调、笔画、五行、寓意、风格标签）
- 精选名字库：62 个（按性别、风格标记）
- 诗词库：50 首，覆盖 诗经 / 楚辞 / 唐诗 / 宋词，每首含名句与全篇正文
- 宠物词库：81 条，按风格分类——萌系(15) / 食物(15) / 拟声(10) / 洋气(15) / 霸气(12) / 文艺(14)

### 数据存储
- 存储位置：本机浏览器 IndexedDB（库名 `nameApp`），刷新、关闭、重启均不丢失。
- 存储内容：取名记录(`records`)、收藏夹(`favorites`)、自定义文献(`materials`)、偏好设置(`settings`)。
- 备份只导出用户数据（上述 4 类），内置数据库不参与导出。

## 3. 安装方法

**普通使用（无需安装）**：
1. 下载/拷贝整个项目文件夹到本机任意位置。
2. 用浏览器（推荐 Chrome / Edge）打开项目根目录的 `index.html` 即可使用。
3. 不依赖任何框架、无需构建、无需服务器，双击即用。

**运行自动化测试（可选，开发者）**：
```bash
# 需要 Node.js 18 及以上
npm install        # 安装开发依赖 jsdom、fake-indexeddb
npm test           # 运行全部单元/集成测试
```

## 4. 使用方法

1. **打开应用**：双击 `index.html`，浏览器中进入"奇思妙取"首页。
2. **快速取名**：在首页"快速 AI 取名"卡片输入姓氏、选择场景（新生儿 / 生辰八字 / 诗词 / 宠物），点「生成」即可看到名字，并可一键跳转到对应模块深化。
3. **上传文献取名**：在首页"上传自定义文献取名"卡片选择本地 `.txt` 文件（诗词、家训、文章等），应用自动提炼可取名汉字并生成候选名，文献会保存到"已保存的文献"中，可反复使用或删除。
4. **进入各模块**：通过左侧导航切换：
   - **新生儿取名**：填姓氏、选性别与风格（可多选）、可填字辈字与避讳字 → 点「生成名字」；不满意点「换一批」；卡片右上角星标收藏。
   - **生辰八字取名**：按"① 出生信息 → ② 排盘结果 → ③ 五行补益推荐"三步走；不填时辰也能出结果（五行判断较粗略）。
   - **诗词取名**：在搜索框输入字/词检索，或用出处下拉筛选；点左侧任意一句诗，右侧栏会显示提炼出的名字（下滑页面时仍可见），每个名字带出处原文。
   - **宠物取名**：选类型/性别，填毛色、性格，点选想要的风格 → 「生成宠物名」；可用「中文名 / 英文名」切换展示。
   - **名字解析及评分**：输入完整名字（如：李承宇）→ 点「解析评分」，查看逐字解析、各维度评分、综合分与点评。
5. **收藏与历史**：任意页面收藏的名字统一进「★ 收藏夹」；所有操作自动记录进「历史记录」。
6. **数据备份**：顶栏「导出备份」下载 JSON 文件；「导入恢复」选择之前导出的 JSON 即可还原全部数据。
7. **设置偏好**：顶栏「设置」可保存默认姓氏、性别、风格、宠物类型，下次进入自动带入。

## 6. 技术栈与项目结构（开发者参考）

- 纯 HTML + CSS + 原生 JavaScript 单页应用，无框架、无构建步骤；为兼容 `file://` 直开，不使用 ES Module，脚本按依赖顺序以普通 `<script>` 加载。
- 本地持久化：IndexedDB（封装见 `js/db.js`）。
- 目录结构：
  - `index.html` — 应用外壳与脚本加载顺序
  - `css/style.css` — 全部样式
  - `js/utils.js` — 工具函数（拼音、五行、农历、谐音检查等）
  - `js/data/` — 内置数据库（汉字库、精选名字、诗词库、宠物词库）
  - `js/engine/` — 取名/排盘/评分引擎（generator、bazi、poetry、score）
  - `js/pages/` — 各页面渲染（home、newborn、bazi、poetry、pet、score、favorites、history、settings）
  - `js/app.js` — 应用外壳（路由、导航、备份导入导出、抽屉）
  - `test/` — 自动化测试（Node 内置 test runner + jsdom + fake-indexeddb）
  - `PRD.md` — 产品需求文档（开发依据）
